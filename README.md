# זמני היום · אור החיים

אתר (PWA) של זמני היום והשבת לפי שיטת לוח אור החיים, עם דבר תורה מובנה לכל פרשה, חג וצום.
אתר סטטי לגמרי: אין שרת, אין תלות ב-API, ועובד גם בלי אינטרנט אחרי הביקור הראשון.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה: עיצוב, חישוב הזמנים, תצוגה |
| `data/bank.json` | מאגר דברי תורה: מפתח לכל פרשה (שם באנגלית כמו ב-hebcal, למשל `Lech-Lecha`) ולכל מועד (`Rosh Hashana`, `Tish'a B'Av`, `Rosh Chodesh`, `Shabbat` וכו') |
| `data/weekly.json` | דבר תורה חדש לכל שבת, לפי תאריך השבת: `{"entries": {"YYYY-MM-DD": {"text", "topic", "written"}}}`. מתעדכן אוטומטית כל יום ראשון |
| `sw.js` | Service Worker לעבודה בלי אינטרנט |
| `vendor/hebcal-core-6.10.0.min.js` | הלוח העברי, הפרשות והחגים ([@hebcal/core](https://github.com/hebcal/hebcal-es6), רישיון GPLv2) |

## שיטת החישוב

- הנץ ושקיעה לפי גובה העיר; שעות זמניות לפי הגר"א (הנץ עד שקיעה).
- עלות השחר 72 דק' זמניות לפני הנץ; טלית ותפילין 60 דק' זמניות.
- מגן אברהם: מעלות השחר עד 72 דק' זמניות אחרי השקיעה.
- צאת הכוכבים 13.5 דק' זמניות; רבנו תם 72 דק' זמניות.
- הדלקת נרות לפני השקיעה המישורית לפי מנהג העיר (ירושלים 40, חיפה 30, שאר ישראל 20, חו"ל 18).
- צאת שבת: ברירת מחדל 8.5°, ניתן לשינוי בהגדרות.

החישוב אסטרונומי לפי כללי הלוח. ייתכנו הפרשים של דקה-שתיים מהלוח המודפס.

## עדכון גרסה

בכל שינוי בקבצים שבמטמון (`index.html`, `bank.json` וכו'), יש להעלות את `VERSION` ב-`sw.js`, כדי שהמשתמשים יקבלו את הגרסה החדשה.
