# זמני היום · אור החיים

אתר (PWA) של זמני היום והשבת לפי שיטת לוח אור החיים, עם דבר תורה מובנה לכל פרשה, חג וצום.
אתר סטטי לגמרי: אין שרת, אין תלות ב-API, ועובד גם בלי אינטרנט אחרי הביקור הראשון.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה: עיצוב, חישוב הזמנים, תצוגה |
| `data/bank.json` | מאגר דברי תורה: מפתח לכל פרשה (שם באנגלית כמו ב-hebcal, למשל `Lech-Lecha`) ולכל מועד (`Rosh Hashana`, `Tish'a B'Av`, `Rosh Chodesh`, `Shabbat` וכו'). הערך הוא `{"pshat", "chassidut", "mussar"}`, או מחרוזת אחת (פורמט ישן, נחשב פשט) |
| `data/weekly.json` | דברי תורה חדשים לכל שבת, לפי תאריך השבת: `{"entries": {"YYYY-MM-DD": {"styles": {"pshat", "chassidut", "mussar"}, "topic", "written"}}}`. מתעדכן אוטומטית כל יום ראשון |
| `tools/check_dvar.py` | בדיקת JSON ומבנה התגיות של כל דברי התורה. להריץ לפני כל commit של נתונים |
| `sw.js` | Service Worker לעבודה בלי אינטרנט |
| `vendor/hebcal-core-6.10.0.min.js` | הלוח העברי, הפרשות והחגים ([@hebcal/core](https://github.com/hebcal/hebcal-es6), רישיון GPLv2) |

## פורמט דבר תורה

שלושה סגנונות, ובכל אחד חמישה חלקים קבועים בסדר הזה. באתר הם מוצגים כטאבים (פשט · חסידות · מוסר), והאתר זוכר את הבחירה האחרונה.

| סגנון | מפתח | החלקים |
|---|---|---|
| פשט | `pshat` | `[פסוק]` `[קושיה]` `[מפרש: ...]` `[חידוש]` `[מסר]` |
| חסידות | `chassidut` | `[פסוק]` `[דיוק]` `[מפרש: ...]` `[נקודה]` `[עבודה]` |
| מוסר | `mussar` | `[פסוק]` `[התבוננות]` `[מפרש: ...]` `[מידה]` `[קבלה]` |

```
כותרת: ...
תקציר: משפט אחד
[פסוק]
ציטוט הפסוק
(מראה מקום)
[קושיה]
...
[מפרש: שם המפרש]
...
[חידוש]
...
[מסר]
...
מקורות: מקור; מקור
```

כל תגית מופיעה פעם אחת בשורה משלה, ואין סוגריים מרובעים במקום אחר. `[מפרש: רעיון]` מציג את הרעיון בלי ייחוס.

## שיטת החישוב

- הנץ ושקיעה לפי גובה העיר; שעות זמניות לפי הגר"א (הנץ עד שקיעה).
- עלות השחר 72 דק' זמניות לפני הנץ; טלית ותפילין 60 דק' זמניות.
- מגן אברהם: מעלות השחר עד 72 דק' זמניות אחרי השקיעה.
- צאת הכוכבים 13.5 דק' זמניות; רבנו תם 72 דק' זמניות.
- הדלקת נרות לפני השקיעה המישורית לפי מנהג העיר (ירושלים 40, חיפה 30, שאר ישראל 20, חו"ל 18).
- צאת שבת: ברירת מחדל 8.5°, ניתן לשינוי בהגדרות.

החישוב אסטרונומי לפי כללי הלוח. ייתכנו הפרשים של דקה-שתיים מהלוח המודפס.

## עדכון גרסה

בכל שינוי בקבצים שבמטמון (`index.html`, `bank.json` וכו'), יש להעלות את `VERSION` ב-`sw.js`, כדי שהמשתמשים יקבלו את הגרסה החדשה.
